# OpenWeather 날씨 웹앱

## 파일
- index.html : 웹페이지 구조
- style.css : 디자인
- script.js : OpenWeather API 호출 및 데이터 처리

## 실행 방법
1. OpenWeather에서 API Key를 발급합니다.
2. script.js의 다음 부분을 수정합니다.

const API_KEY = "여기에_본인의_API_KEY를_입력하세요";

3. index.html을 브라우저에서 실행합니다.

주의:
API Key를 GitHub에 공개 저장소로 올리면 다른 사람이 볼 수 있습니다.
학습용으로 사용하고, 실제 공개 서비스에서는 서버 환경변수 등을 사용하는 방식을 권장합니다.
